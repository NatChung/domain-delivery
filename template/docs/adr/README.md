# Decision records

Hub-specific decisions only: local boundaries, tooling, routing and process
choices that belong to {{PROJECT}}.

Shared-method decisions are pinned upstream and must not be copied here — read
them at
[`../../.domain-delivery/docs/adr/README.md`](../../.domain-delivery/docs/adr/README.md).

Number Hub ADRs from `0001` in this folder. Upstream method ADR numbers are a
separate sequence; do not renumber against them.
